## 怎样增加新技巧

1. 在 `Ilearned/` 下新建名称清楚的 `.md` 文件，例如 `uart-terminal.md`。
2. 按下面的结构记录，写清适用条件、操作对象和验证方法。
3. 在上方表格加入口，检查链接后按正常流程提交、同步到 GitHub。

建议结构：

```markdown
# 技巧名称

日期：YYYY-MM-DD

## 遇到什么问题
记录现象和适用条件。

## 先确认什么
列出需要检查的文件、当前状态和需要保留的成果。

## 操作步骤
按实际顺序填写；涉及覆盖或删除时先备份，写清操作范围。

## 怎样确认成功
记录检查方式、实际结果，以及尚未验证的部分。

## 这次学到了什么
用自己的话总结，下次需要注意什么。
```

这里的笔记会公开到 GitHub；完整日志、设备标识和临时备份继续放在被忽略的本地目录。配置文件出现变化不一定是错误，先比较内容，再决定是否撤回。
