# NUCLEO-F446RE：按功能模块推进的学习计划

生效日期：2026-10-31。主板：NUCLEO-F446RE。最终作品：**可配置的数据采集仪**。

## 目标与方法

取消固定周数和每节课的时间配额，按功能验收推进；完成一个模块的可运行成果，再进入下一个模块。每个模块先独立运行，再逐步合入作品。

以 *Mastering STM32 — Second Edition* 为主线，野火 F4 HAL 教程作为驱动移植参考。优先借助 AI 跑通工程、熟悉 VS Code、完成小改动；书本用于解释当前涉及的代码、编译和硬件原理，英语按需学习。野火配套板的引脚、时钟及工程配置需按 F446RE 核对，不能直接照搬。

## 每个模块的固定学习流程

1. **先运行完整例程**：明确独立工程、入口文件、任务和预期现象。尚未移植的作者 CubeIDE 工程只能作参考，需先适配并验证后再标记为可运行。
2. **让 AI 做一个小改动**：说明需求和修改范围，查看差异，再编译；不要求一次彻底理解所有代码。
3. **完成实际验证**：沿用完整 Flash 备份、目标核对和下载校验流程；分别记录编译结果、烧录结果和硬件现象，任何一步失败都停止后续写入。
4. **按需理解与复盘**：只讲本次涉及的接口、数据流和必要原理，记录问题与下一步；英文只处理需要的术语或难句。Git 提交由用户操作，助手提供逐项变更说明。

各实验工程继续与现有项目平级，各自维护源代码、构建目录和操作记录。教材阅读区保存章节定位、学习进度和实验链接；本计划不提前创建后续工程或购买器材。

## 下一模块：串口交互与基础调试

复用现成的 [book-debugging](../../book-debugging/README.md)，入口为 [Core/Src/main-ex1.c](../../book-debugging/Core/Src/main-ex1.c)，不另建工程、不需要外接模块。配套阅读为[第 5 章（仅本地）](chapters/05-introduction-to-debugging.md#source-p147)，按需看调试链路和 I/O 重定向；原书 CubeIDE 菜单对应当前工程的 VS Code 任务。

本节待执行的操作顺序：

1. 保持型号工作区的 **STM32 配置文件**。若 CubeProgrammer 仍连接目标，先断开；不要同时开启多个调试连接。
2. 选择 **Build (Debug) · book-debugging**，核对终端所属目录和生成的 ELF、HEX、BIN。
3. 经板载 ST-LINK VCP 打开串口，设置 **115200 / 8N1 / 无流控**；以本次枚举的串口号为准，不固定 COM8。若所选终端提供行尾设置，使用 CRLF；串口只打开一份。
4. 选择 **Flash (backup + verify) · book-debugging**，等待完整备份、下载校验和复位成功；没有提示时在串口已打开后按黑色 RESET。
5. 看到 `How many times to print the message?:` 后输入 `3` 并回车，应依次输出 `Hello, Nucleo: 1`、`2`、`3`，行间约 500 ms，然后停止打印。停止打印后不会自动重新询问；LD2 不闪烁是这个例程的正常行为。
6. 运行 **Configure Cortex-Debug paths · book-debugging**，在 `scanf` 后的 `printf("\r\n")` 行设断点，按 F5 选择该工程的 **Attach STM32F446RE (no download)**；必要时按项目说明复位程序，再从串口输入 `3`。确认断点命中、`uTimes == 3`，单步观察循环变量。附加调试使用的 ELF 必须对应刚烧入的固件。
7. 在[进度记录](notes/progress.md)中分别填写串口、断点、单步和变量观察的实际结果，再做一个小改动；这些步骤目前均未完成硬件验收。

现有工程说明中的失联记录属于此前历史；以[连接恢复复盘](notes/03-stlink-recovery.md)理解其背景，不能把旧记录当作新的连接测试结果。当前恢复记录来自 HAL 闪灯工程，不替代 CH5 本身的串口和 GDB 验收。

## 当前起点与约定

- 已验收的 HAL 闪灯固件是 **亮 100 ms、灭 900 ms**，用户确认绿色 LD2 闪烁；精确时序、实体 RESET 和断电重启未单独确认。
- 后来源码中的 **亮 100 ms、灭 2000 ms** 是另一版修改，尚未补充本课程的独立验收证据；不改写旧的 100/900 ms 校验记录，也不在本次重新编译或烧录它。
- 初期使用现有开发板和 USB；传感器、OLED、MicroSD 到对应模块开始前再核对现有器材、接口和供电。采购不作为前面模块的前置任务。
- 进度只记录真实完成的操作；待开始、材料已准备、编译通过、烧录通过、硬件现象通过分别标记。详细日志和 Flash 备份只保留在本地。
- 本次只调整学习计划与文档入口，不修改工程、烧录硬件、暂存或提交代码。
