# CH20 本代码所用 API 说明

本章用裸寄存器启动与链接脚本观察.data/.bss/.rodata和堆，不是标准HAL固件。正常子例静态预期为PA5闪灯，ex4/ex5含原始比较/内存风险，尚未烧录或硬件验收。

核对日期：2026-10-31。入口与例程选择见 README，源码来自清单固定提交；统计基于本学习工程当前源码。

## 统计范围

覆盖全部 main 变体、工程 BSP、MSP、IRQ、时基、标准I/O适配；CH26额外覆盖FatFs/SPI磁盘适配和配置解析，CH27覆盖USB_DEVICE应用及PCD适配。只统计这些文件直接调用的外部函数和功能宏，跨例按名称去重；不递归统计 HAL/CMSIS/FreeRTOS/FatFs/W5500/USB中间件内部实现。Core/Src/system_stm32f4xx.c是ST系统模板，不纳入应用直接清点；TI AES算法只列直接接口。

外部 API 去重 **4** 个，其中 HAL/CMSIS功能宏和接口 0 个，其余标准库/RTOS/文件系统/网络/USB/AES接口 4 个。项目函数、IRQ/回调、运行库入口和项目宏另列，常量/类型/函数定义不计。条件/错误/模板按卡注明，预设没有启用的代码不冒充已运行。

## 核心功能实现的 API 链

图例：`→`为顺序调用，`⇝`为硬件/内核事件触发，`⇢`为数据流；“内部依赖”不计入直接API数量。

初始化（顺序 →）：向量表首项 MSP=SRAM_END，第二项→main(ex1) 或 _start(ex2–5)→__initialize_data；ex3–5 再→__initialize_bss→main。位置：各 main-exN.c 的 vector_table、_start。
核心业务（顺序 →）：main→写 RCC/GPIOA 寄存器→写 GPIOA_ODR→delay→写 GPIOA_ODR；验证点：PA5 ODR 位与离线 map 的段地址。
数据流（⇢）：Flash .data 装载区⇢SRAM .data；零值⇢.bss；Flash .rodata⇢比较表达式。ex5 malloc→newlib 内部堆管理→项目 _sbrk（内部依赖，不纳入应用直接 API 数）⇢heapMsg→strcpy→strcmp。
中断（硬件触发 ⇝）：未提供完整中断处理链。错误分支：ex5 堆界检查→BKPT；没有通用 HAL Error_Handler。

## 项目封装、回调及运行库入口

| 名称 | 本工程作用 |
| --- | --- |
| `__initialize_bss` | 把 SRAM 的 .bss 逐字清零 |
| `__initialize_data` | 把 Flash 中的初值逐字复制到 SRAM 的 .data |
| `_sbrk` | newlib堆增长入口；堆/栈边界由当前链接脚本提供，CH20使用专门实验实现 |
| `_start` | 自定义复位入口：建立 C 数据区后调用 main |
| `delay` | 空循环延时，仅用于裸机启动/链接实验，不是精确定时 |
| `main` | 应用入口：完成初始化，再进入本子例的循环或调度器 |
